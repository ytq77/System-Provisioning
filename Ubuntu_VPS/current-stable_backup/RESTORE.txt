Restore only to a compatible, trusted Ubuntu host.
This archive contains private keys, passwords, subscription addresses, and SSH authorization data.
1. Install compatible sing-box, Caddy, iptables-persistent, and OpenSSH packages.
2. Stop sing-box and Caddy.
3. From /, extract current-stable-config.tar.gz while preserving owners and modes.
4. Run systemctl daemon-reload and sysctl --system.
5. Validate sing-box, Caddy, sshd, IPv4 rules, and IPv6 rules before applying them.
6. Enable the saved services and timer, then restart the host and repeat all validation checks.
